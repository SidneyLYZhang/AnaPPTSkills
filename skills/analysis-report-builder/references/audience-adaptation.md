# 受众适配矩阵

> 核心原则：**一份结论、按受众裁剪呈现**，不是做三份独立报告。阶段0 就确认主受众与次受众，它决定后续每一步的深度与语言。管理层的裁剪是**按决策问题重写**，不是删掉细节。

| 维度 | 管理层 | 业务人员 | 外部人员 |
|---|---|---|---|
| 核心诉求 | 决策依据 | 操作指引 | 可信度 / 合规 |
| 篇幅 | 报告 ≤15 页 + 一页纸摘要 | 详细版 + 分场景操作建议 | 完整版 + 附录 |
| 语言 | 结论 + 影响 + 建议，少术语 | 结合业务场景，术语带解释 | 中立客观，方法透明 |
| 证据强度 | 关键证据 + 风险提示 | 详细数据 + 操作步骤 | 全部来源 + 方法论 + 局限声明 |
| 建模呈现 | 结论 + 置信度，不展开技术 | 模型怎么用于日常工作 | 技术细节 + 验证过程 |
| 图表 | 1-2 张核心图，标题标结论 | 分场景图表 | 完整图表 + 附录 |

## 各受众写作规范

### 管理层版
- 开头一页纸摘要：背景一句话、核心结论 ≤3 条、建议与资源需求、风险与不确定性。
- 每个结论配"如果采纳/不采纳的影响"。
- 技术术语一律替换为业务语言；必须保留的术语在首次出现时括注解释。
- 不展示中间过程数据，只展示支撑结论的关键证据。

### 业务版
- 每个结论落到"业务场景 → 操作动作 → 注意事项"。
- 保留完整数据细节与口径说明，方便业务自行复算验证。
- 建模结果呈现"输入什么、输出什么、在流程哪一步用"。

### 外部版
- 方法透明：数据来源、处理方法、模型验证过程完整可查。
- 局限声明独立成节：样本偏差、时效、可比性问题如实列出。
- 避免绝对化表述；每个判断标注置信度或证据等级。

## 常见坑

1. **删减版冒充管理层版**：删减保留了太多细节，管理层看不到重点。管理层版按"决策问题"组织章节，不是按"分析过程"组织。
2. **一套语言打三类人**：给外部人员的报告用内部黑话，给管理层的报告堆技术细节——决策门A 确认的语言规范在阶段5/6 每章自查一次。
3. **证据强度一刀切**：管理层版本把所有来源堆上显得臃肿，外部版本省略方法论显得不可信。按矩阵配证据。
