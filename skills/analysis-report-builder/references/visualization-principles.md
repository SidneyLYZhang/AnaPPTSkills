# 数据可视化准则（信 · 达 · 雅）

> 用途：本技能全部可视化产出的唯一权威。阶段 2 选图表类型（第二节）→ 阶段 4 立项配图（`assets/templates/06-分析大纲.md`）→ 阶段 5 设计与解读（第三～六节）→ 阶段 6 PPT 重绘（第二、三、六节）时读取。
> 三准则按优先级排序：**信**（图形诚实）→ **达**（传达高效）→ **雅**（赏心悦目）。**违信即废图**；先过信与达，再谈雅。

---

## 一、信：图形诚实性（第一道门槛，过关才进设计）

### 三条硬规

**1. 比例守恒——谎言因子 LF 落在 [0.95, 1.05]**

LF = 图形元素的相对变化量 ÷ 数据本身的相对变化量。LF = 1 表示图形未扭曲数据；超出 [0.95, 1.05] 即丧失可信度。

| 看到 | 改成 |
|---|---|
| 柱状图 Y 轴从非零值起（如从 90 起），差异被放大 | 自 0 起；确有必要的走势对比，把该判断移到折线图，并在轴上标截断符号 + 正文说明截断 |
| 3D 柱体、3D 饼图（透视使近处显得更大） | 平面 2D |
| 用半径/面积/体积编码数值（2 倍数值画成 4 倍面积） | 用长度或位置编码数值 |
| 用插画/图标大小表示数值，且大小与数值不成比例 | 插画只作类别标识；数值改用长度/位置/直接标注 |

**2. 比较自带参照系（不断章取义）**

时间窗、基数、对比对象三者缺一即成误导。典型：只截取利好时段（完整时间轴才能看出自然波动）；只给增长百分比不给基数（小基数高增长）；只给排名不给分母；把季度峰值与月度均值并列比较。

**3. 呈现数据的变化，不呈现设计的变化**

同类元素必须共用同一编码尺度，不为突出某一段而单独放大该段——放大后的高度代表不同的数量单位，读者无法再做比较。要突出就改**颜色与标注**，不改**比例**。

### 完成判据

每张图自问一句："**只看这张图、不看正文，读者会不会得到一个与数据不符的印象？**" 答"不会"才过关。答"会"或"不确定"，回上表改。

## 二、选型：先定要表达的"相对关系"，再定图表

**第一步不是挑图表，是写出这张图要表达的关系。**关系定了，图表随之而定：

| 要表达的关系 | 典型场景 | 图表 | 编码通道 |
|---|---|---|---|
| 单个值 / 达成率 | 实时交易额、KPI 达成 | 指标卡、靶心图 | 位置 + 文字标注 |
| 比较与排序 | 各区域销售额对比 | 柱状图；类别多或名称长用**横向条形图**；多维度少量对象用雷达图 | 长度 / 位置 |
| 占比与构成 | 市场份额、成本结构 | 饼图/环形图（类别 ≤5~7）、百分比堆积柱、矩形树图 | 角度（限于少量类别）/ 长度 |
| 时间趋势 | 月度销量走势 | 折线图；强调总量累积用面积图 | 位置 |
| 分布与离散 | 年龄/收入分布 | 直方图、箱线图、散点分布 | 位置 |
| 相关性 | 两变量关系 | 散点图；三变量用气泡图（用大小编码第三变量） | 位置 + 大小 |
| 地理分布 | 各省销售额 | 地图、热力地图 | 位置 + 色阶 |
| 流程与转化 | 各环节转化率 | 漏斗图 | 长度 + 位置 |
| 多维构成 + 对比 | 总量 + 内部结构 | 堆积柱状图、组合图（柱 + 折线） | 长度 + 位置 |

**编码效率排序**（决定"通道用哪个"，来自 Cleveland & McGill 的感知精度研究，越靠前越准越快）：

- **数量通道**（编码数值）：位置 ＞ 长度 ＞ 角度 ＞ 面积 ＞ 深度 ＞ 色温 ＞ 饱和度 ＞ 曲率 ＞ 体积。
- **标识通道**（编码分类）：空间区域 ＞ 色向（色相）＞ 动向 ＞ 形状。

### 五条选型规则

1. **数值走数量通道的前排（位置/长度），分类走标识通道（颜色/形状）。** 颜色承担分类与强调，不承担精确数值——读者读不出"深蓝比浅蓝多 7%"。
2. **类别超过 5~7 个时，占比类图表改用条形图/堆积柱**（人眼对长度比对角度、面积更敏感）。
3. **比较多个时点的占比变化用折线或堆积柱**，不用多个并排饼图。
4. **一图一结论**：一张图只承载一个论点；出现第二个论点就拆图，而不是加一条轴。
5. **按效率排序取前排**：同一关系有多种画法时，选编码效率更靠前的那个——有位置就不用角度，有长度就不用面积。

**易漏项**：多折线无区分标识（每条线直接标注）；双 Y 轴强行对齐两个不同量纲、制造"同步"错觉（改分图，或对其中一条指数化并注明基准）。

## 三、达：压缩"感知 → 识别 → 推理"三步的耗时

感知处理分三步，每一步都有对应的压缩手段：

| 步骤 | 手段 |
|---|---|
| ① 感知原始信号 | 用**预感知属性**（色调、形状、长短、方向、大小、密度）——这类属性在约 200ms 内可被快速辨识与区分 |
| ② 模式识别 | 用**格式塔原则**让分组一眼可见：邻近（近的归一组）、相似（同形同色归一组）、连通、连续、封闭、对称、图形与背景、共同命运（同向运动归一组） |
| ③ 推理分析 | 用第二节的**编码效率排序**，缩短"看清→看懂"的时间 |

### 三条执行规则

1. **最大化数据墨水占比**：擦除不表达数据的墨水（网格线、边框、背景填充、3D 阴影、图例外框、装饰图标）；坐标轴与刻度保留但弱化——**网格线浅灰、线宽 ≤0.5pt；轴线黑色或深灰、线宽 ≤1pt**。冗余数据墨水（如为可辨识而保留的对称结构）可留，纯装饰的一律删。
2. **直接标注优先于图例**：能贴在线上/柱端/点上方的标签就不放图例框——图例迫使读者在图形与图例之间来回对照，占用工作记忆。类别过多无法直接标注时，才退回图例并把图例按图形顺序排列。
3. **用视觉显著性制造主次**：突出项用暖色、高饱和、大字号、粗线；背景项用冷色、低饱和、小字号、细线。**一张图只留一处最强调**——处处强调等于没有强调。

## 四、雅：让人愿意读下去

1. **颜色有语义、有节制**：温度用红高蓝低这类符合直觉的映射；同一指标在全文（含 PPT）保持同色；同图配色类别数 ≤ 必要类别数（一般不超 5~7）；连续量用同色系深浅表达强弱，不混用红绿对立色系（色觉障碍者不可辨）。
2. **布局可预测**：同类图同布局；图内元素顺序与正文叙述顺序一致（如一律降序排列，且排列方向与阅读方向一致）；多图之间顺序一致、衔接明确。
3. **图题即结论**：图题写成该图要传达的那一句话（"华东拖累整体增速 3.2pp"），而不是中性名（"各区域销售额"）。
4. **层次与位置**：最重要的视图放**顶部或左上**；一屏（一页）视图数 ≤3~4 个，超出则大局被细节淹没；同类或共用的筛选项/图例成组，用浅色边界提示"它们是一组"。
5. **文字克制而有指向**：注释只落在拐点、异常、背离、关键事件上（季节高峰、政策节点、竞品动作），不重复图上已可读出的数字；文字过量会与图形争夺注意力。
6. **对齐、留白、无装饰**：网格化对齐，保留呼吸感；背景保持素净，不用条纹、渐变、剪贴画填充。
7. **缩到 1/3 尺寸仍可读**：投屏与移动端场景下，结论不能依赖精细细节（密点、细线、小字）。做法：减少数据点、加粗线条、放大标注、必要时为该场景单独出一版简图。

## 五、受众与媒介适配

三类受众（管理层 / 业务人员 / 外部人员）的图表策略以 `references/audience-adaptation.md` 受众矩阵为准。本节只补可视化特有的两条维度：

**读者熟练度**
- 新手读者：结构清晰、选项少，直接用文字点出"该看什么、该得出什么"。
- 专家读者：允许高密度与高细节，保留自行探索空间——细节与数据密度优先于简洁。

**媒介**
- 交互（HTML / 在线版）：**默认视图即完整**——关键数字在默认状态直接可见，不放 hover、筛选器、折叠面板之后（实证：交互式可视化的点击率通常仅 10%~15%）。交互只用于承载附加数据、深层探索，或作为引入钩子。
- 投屏与移动端：结论不依赖精细细节，缩到 1/3 尺寸仍可读（见第四节第 7 条）。

## 六、交付前自检（每张图逐条过）

> 高频翻车点：非零起点 · 3D 柱饼 · 面积编码数值 · 只给增幅不给基数 · 图题缺结论句 · 关键数字靠读者自己算。

- [ ] **信**：比例守恒（LF ∈ [0.95, 1.05]）；时间窗/基数/对比对象完整；未用设计手段替代数据差异
- [ ] **达**：编码通道在效率前排；非数据墨水已清；关键点直接标注；全图仅一处最强调
- [ ] **雅**：配色有语义且类别数必要；图题即结论；视图排序符合阅读顺序；缩至 1/3 仍可读
- [ ] **三要素**：标题（结论句）+ 来源（含 `data_asof`）+ 单位与口径
- [ ] **一图一结论**，且正文完成"引出—读图—落点"三段（写作侧规则见 `references/report-writing-llm-spec.md` 第六节）
