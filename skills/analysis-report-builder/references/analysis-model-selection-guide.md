# 分析模型与分析手段选型决策指南

> 用途：作为分析报告类 Agent Skill 的补充知识，指导 LLM 在拿到分析目标和数据后，**决策"用什么分析模型/分析手段"**，而不是"先套框架再找数据"。
>
> 核心原则：**逆向思考——先明确要回答的问题是什么，再选分析框架/模型/手段；框架之间不互斥，可组合使用。**

---

## 〇、选型总决策流程（五问法）

在选定任何模型之前，依次回答五个问题，答案即选型依据：

1. **分析目标是什么？** —— 要回答哪类问题（发生了什么 / 为什么 / 将会怎样 / 该怎么做 / 如何呈现）
2. **业务问题域是什么？** —— 战略、市场、用户、运营、财务、产品……决定用哪类商业框架
3. **数据条件是什么？** —— 数据类型（分类/连续/时序/文本/无标签）、样本量、分布形态、质量，决定统计/建模手段的可行边界
4. **约束条件是什么？** —— 可解释性要求、时间紧急程度、分析深度、报告受众，决定复杂度取舍
5. **输出要支撑什么决策？** —— 结论型、诊断型、建议型、预测型，决定分析链条的长度

**关键取舍规则**：
- 对问题了解程度低 → 用**问题树**（广而全地拆解可能性）；对问题已有较明确判断 → 用**假设树**（深而快地验证）。
- 紧急汇报 → 假设树优先，逻辑树深度控制在 2~3 级；深度诊断 → 问题树优先，深度 4~5 级。
- 数据基础薄弱时，优先描述性与诊断性分析（投入产出比最高）；预测/规范性分析依赖数据质量，数据不牢时容易产出"精确的错误"。

## 一、按分析层次选型：四类分析的定位与前提

| 分析类型 | 回答的问题 | 典型手段 | 前提条件 | 产出形态 |
|---|---|---|---|---|
| **描述性分析** | 发生了什么？ | 对比分析、趋势分析、构成/结构分析、分布分析、描述统计 | 有结构化历史数据、指标口径统一 | 看板、报表、趋势摘要 |
| **诊断性分析** | 为什么会发生？ | 漏斗分析、群组(Cohort)分析、归因分析、维度下钻、指标拆解 | 可按有意义维度切分数据、粒度足够细 | 根因解释、差异归因 |
| **预测性分析** | 将会发生什么？ | 回归预测、时间序列、分类模型、情景模拟 | 有干净的、带标签的历史数据 | 预测值、概率评分 |
| **规范性分析** | 应该怎么做？ | 优化模型、仿真、推荐动作 | 能定义目标函数与约束条件、前述三类已扎实 | 行动建议、最优分配方案 |

**if/then 速判**：
- 问题 = "发生了什么" 且有历史数据 → 描述性
- 问题 = "为什么" 且数据可分维度 → 诊断性
- 问题 = "未来会怎样" 且有带标签历史数据 → 预测性
- 问题 = "该怎么做" 且能定义目标与约束 → 规范性

**注意**：四者是递进关系（成熟度 L1 报表 → L2 下钻诊断 → L3 受治理的预测 → L4 嵌入式决策），**不可跳级**——没有扎实的描述性基础就上预测模型，大概率建在口径混乱的数据上。

## 二、按业务目标选型：常用商业分析框架对照表

| 分析框架 | 解决的问题 | 适用场景（触发信号） | 不适用/注意事项 |
|---|---|---|---|
| **对比分析** | 现状与基准的差异 | 任何分析的第一步；环比/同比/定基比/对标 | 对比基准要可比，否则结论无效 |
| **结构/构成分析** | 内部各部分占比及变化 | 成本结构、收入结构、用户构成 | 占比之和=100%；搭配时间维度看结构迁移 |
| **漏斗分析** | 关键环节流失在哪 | 优化转化效率、用户在流程中流失 | 流程节点必须明确定义 |
| **AARRR 海盗模型** | 增长链路哪个环节弱 | 用户增长：获客→激活→留存→变现→传播 | 互联网产品生命周期分析 |
| **RFM 模型** | 用户价值分层 | 精细化运营、客户分层、营销资源分配 | 基于固定时间点快照；适合交易型业务 |
| **CLV/LTV** | 用户长期价值 | 获客成本核算、ROI 评估、留存策略 | 需要留存率与消费数据 |
| **UJM 用户旅程地图** | 体验路径诊断 | 体验优化、触点诊断 | 偏定性+定量结合 |
| **SWOT** | 内外部态势盘点 | 战略规划、进入策略、竞争分析 | 避免主观臆断；需结合数据佐证 |
| **PEST/PESTEL** | 宏观环境影响 | 市场进入研究、政策风险评估 | 注意地区差异，避免泛泛而谈 |
| **波特五力** | 行业竞争强度 | 竞争格局分析、进入可行性 | 按行业特点调整权重 |
| **BCG 矩阵** | 产品组合资源分配 | 产品组合管理、投资决策 | 需动态跟踪，避免静态分析 |
| **STP** | 市场细分与定位 | 品牌定位、差异化营销 | 细分标准要有可操作性 |
| **4P/4C** | 营销策略组合 | 产品、定价、渠道、促销方案 | 营销方案设计 |
| **杜邦分析** | 指标逐层拆解 | 财务分析、ROE 拆解、利润归因 | 强调拆分思路而非具体方法 |
| **5W2H** | 问题澄清 | 需求澄清、问题定义阶段 | 分析前的前置工具 |
| **金字塔原理/MECE** | 结论组织 | 报告结构化表达 | 相互独立、完全穷尽 |

**快速选择决策树（按核心目标）**：
- 核心目标 = 优化转化效率 → **漏斗分析**
- 核心目标 = 用户增长 → **AARRR**
- 核心目标 = 客户分层/精细化运营 → **RFM**
- 核心目标 = 体验路径诊断 → **UJM**
- 核心目标 = 市场进入/行业评估 → **PEST → 波特五力 → SWOT**（按此顺序组合）
- 核心目标 = 产品组合取舍 → **BCG 矩阵**
- 核心目标 = 指标异动归因 → **指标拆解 + 归因方法**（见第四节）

**框架使用要点**：分析目标 → 公司/行业特性 → 可获得的数据资源，三者共同决定选哪个框架；框架之间不互斥，常见组合是"宏观框架定方向 + 数据模型给证据"。

## 三、按数据与问题类型选型：统计与建模方法

### 3.1 统计检验选择——"三步法"决策矩阵

选方法之前，先问三个问题：**① 因变量是什么类型？② 比较几个组？③ 数据是否满足正态/方差齐性？**

| 因变量类型 | 组数/设计 | 前提条件 | 推荐方法 | 非参数替代（不满足前提时） |
|---|---|---|---|---|
| 分类变量 × 分类变量 | 任意 | 80% 单元格期望频数 ≥5 | 卡方检验 | Fisher 精确检验（期望频数过小） |
| 连续变量 | 两组独立 | 正态 & 方差齐 | 独立样本 t 检验 | Mann-Whitney U |
| 连续变量 | 两组独立 | 正态但方差不齐 | Welch's t 检验 | — |
| 连续变量 | 两组配对 | 差值正态 | 配对样本 t 检验 | Wilcoxon 符号秩检验 |
| 连续变量 | 三组及以上 | 正态 & 方差齐 | 单因素 ANOVA | Kruskal-Wallis |
| 连续变量 | 三组及以上 | 方差不齐 | Welch's ANOVA | — |
| 两连续变量 | 相关关系 | 线性 | Pearson 相关 | Spearman（有序/非线性）/ Kendall（分类） |
| 连续因变量 | 预测/解释 | 线性关系 | 线性/多元回归 | 树模型等非线性方法 |

**配套规则**：
- ANOVA 显著 ≠ 知道哪两组不同 → 必须做事后检验：全部两两比较用 **Tukey HSD**；只与对照组比较用 **Dunnett**；方差不齐用 **Games-Howell**。禁止直接做多次两两 t 检验（第一类错误膨胀）。
- 样本量 > 30 时，中心极限定理使 t 检验/ANOVA 对正态偏离具有一定稳健性；小样本且明显偏态 → 坚决用非参数检验。
- 卡方只能判断"是否关联"，关联强度看 **Cramer's V**；t 检验要看 **Cohen's d** 效应量；**不要迷信 p 值**——p<0.05 只说明"差异显著"，不说明"差异重要"，必须同时报告效应量与置信区间。
- 正态性判断：小样本用 Shapiro-Wilk；大样本看 Q-Q 图（大样本下 SW 检验过于敏感）。

### 3.2 机器学习模型选择——五步流程

**Step 1：明确问题类型**
- 监督学习：因变量连续 → 回归；离散 → 分类
- 无监督：分组 → 聚类；压缩 → 降维；关联 → 关联规则
- 其他：时序预测 → 时间序列模型；异常检测；推荐排序

**Step 2：按数据特征筛候选（决策矩阵）**

| 数据特征 | 推荐 | 避免 |
|---|---|---|
| 样本量 < 1K | 逻辑回归、朴素贝叶斯、SVM、决策树 | 深度学习、XGBoost（易过拟合） |
| 样本量 1K~100K | 随机森林、XGBoost、LightGBM | — |
| 样本量 > 100K | LightGBM、CatBoost、深度学习 | SVM、KNN（太慢） |
| 特征 > 10000 / 高维稀疏文本 | 朴素贝叶斯、线性模型、线性 SVM | KNN、决策树（维度灾难） |
| 非线性关系 | 树模型、核 SVM、神经网络 | 线性/逻辑回归 |
| 大量缺失值 | 随机森林、XGBoost（原生支持） | SVM、KNN、神经网络 |
| 类别严重不平衡 | BalancedRF、XGBoost+权重 | 朴素贝叶斯、KNN |
| 特征强共线 | Ridge、随机森林、PCA+模型 | Lasso（不稳定）、线性回归 |

**Step 3：按业务约束收敛**
- 必须白箱解释（金融风控、医疗、合规）→ 线性/逻辑回归、决策树
- 可事后解释 → 随机森林/GBDT + SHAP、EBM
- 黑箱可接受（推荐、图像）→ XGBoost、深度学习
- 表格数据精度优先 → LightGBM/XGBoost/CatBoost（表格数据上 GBDT 通常仍优于深度学习）

**Step 4：基线先行** → 哑基线（必须超过）→ 简单基线（逻辑回归）→ 强基线（随机森林）；复杂模型无显著提升就不上复杂模型。

**Step 5：交叉验证 + 统计检验** 对比候选，差异需显著才换模型；奥卡姆剃刀：同等性能选最简。

### 3.3 时间序列

| 场景 | 推荐 |
|---|---|
| 单变量、平稳/季节性 | ARIMA / SARIMA |
| 趋势+季节+节假日，要省心 | Prophet |
| 多变量相互影响 | VAR |
| 长依赖、复杂模式、数据量大 | LSTM/GRU、时序 Transformer |

## 四、指标异动归因方法选型

**标准流程**：① 指标拆解（前提）→ ② 计算各因素影响度 → ③ 定位 TopN 影响因子。

**指标拆解参考三层结构**：L1 内外因素拆分（宏观）→ L2 指标结构拆分（中观）→ L3 维度组成拆分（微观）；优先复用现成业务指标体系，不从零拆解。

| 归因方法 | 原理 | 适用场景 | 复杂度 |
|---|---|---|---|
| **连环替代法/差额计算法** | 从基期数据出发，每次只替换一个因素，差异即该因素影响度 | 指标由多因素构成（乘除关系清晰） | 低 |
| **波动贡献法** | 计算各维度波动对整体波动的贡献占比 | 维度下钻式归因 | 低 |
| **杜邦拆解** | 指标按公式逐层拆分 | 财务指标（ROE、利润率） | 低 |
| **多元回归** | 各变量对目标的边际影响 | 多因子、因素间非确定性关系 | 中 |
| **LIFT 模型** | 有无某因素的效果提升对比 | 营销活动、运营测试、A/B | 低-中 |
| **Shapley 值归因** | 博弈论分摊各因素贡献 | 多渠道投放、广告归因 | 高 |
| **路径分析/结构方程** | 建立因果路径，分解直接/间接影响 | 复杂业务流程、机制研究 | 高 |

**归因结论标准话术**："X 指标本期环比基期下降 n%。经下探发现，A 因素变化 N，对整体变化贡献 m%。"

## 六、选型常见误区（反模式清单）

1. **先选框架再找问题** —— 应从业务问题反推框架。
2. **越复杂的模型越好** —— 奥卡姆剃刀；复杂模型必须显著超越基线才值得用。
3. **只看准确率** —— 按业务目标选指标（F1/召回/PR-AUC 等）。
4. **跳过基线直接上复杂模型**。
5. **多组比较用多次两两 t 检验** —— 第一类错误膨胀，应 ANOVA + 事后检验。
6. **忽略正态性/方差齐性前提** —— 选错检验比不检验更危险。
7. **迷信 p 值** —— 必须结合效应量与业务意义。
8. **忽视数据质量与口径统一** —— 指标口径未统一就上分析工具，等于在错误地基上加楼。
9. **忽略部署/解释性约束** —— 训练精度高但推理慢或不可解释的模型可能不可用。
10. **过度调参** —— 收益递减，数据与特征工程收益更大。
11. **分析层次跳级** —— 描述性基础不牢就上预测/规范性分析。
12. **框架机械套用** —— 应结合具体业务构建定制化问题树，而非背诵预制模板。

## 七、给 LLM/Skill 的执行建议

将上述知识嵌入 Skill 时，建议按以下结构组织 LLM 的决策动作：

1. **意图识别先行**：从分析目标中抽取问题类型关键词（"趋势/对比/为什么/预测/怎么办/占比/转化/归因/竞争/增长"），映射到第一节的分析层次与第二节的框架。
2. **决策路径显性化**：要求 LLM 在输出前显式回答"五问法"（目标、问题域、数据条件、约束、决策支撑），把选型理由写入报告或中间产物，便于审计。
3. **默认组合而非单选**：常规报告 = 描述性（对比+趋势+结构）打底 → 诊断性（下钻/归因）深化 → 视数据条件决定是否进入预测层。
4. **触发即提示前提**：选定统计/建模方法时，同时列出该方法的前提条件与验证方式（如"用 t 检验 → 先做 Shapiro-Wilk 正态性检验"），前提不满足时自动切换到替代方法。
5. **复杂度守恒**：紧急/简报场景默认浅层方法（对比、趋势、简单归因）；深度场景才启用问题树全拆解、回归/机器学习建模。
