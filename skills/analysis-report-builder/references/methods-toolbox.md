# 阶段2 方法工具箱（咨询式 / 经营式）

> 选型原则：先定报告类型，再选方法。两者共用同一套 SOP，只是工具箱不同；混合报告按子问题分别选型。每个方法都必须能回答"需要哪些数据、产出什么证据"。

## 一、咨询式（框架驱动，外部视角，结论导向）

适用：战略决策、市场进入、竞品分析、商业模式评估。

| 方法 | 回答的问题 | 核心数据需求 | 常见陷阱 |
|---|---|---|---|
| 波特五力 | 行业竞争格局与吸引力 | 行业集中度、替代品、上下游议价信息 | 五力全列一遍但无评分与证据 |
| 价值链分析 | 利润在哪一环、能力短板在哪 | 各环节成本/毛利结构、内部能力盘点 | 画图了事，没有利润分布数字 |
| 对标分析 | 与标杆差距在哪 | 标杆的公开数据（财报/报告/官网），标注时效 | 对标对象选错；只比结果不比过程 |
| PEST / 宏观扫描 | 外部环境变量 | 政策、经济、社会、技术公开信息 | 罗列信息，没有"对本项目的影响" |
| SWOT | 综合态势 | 由上述方法产出后归纳 | 作为起点直接用，沦为头脑风暴清单 |
| 假设检验树 | 核心论断是否成立 | 每个子假设的可证伪证据 | 假设不可证伪（无法被数据推翻） |

## 二、经营式（指标体系驱动，内部视角，诊断导向）

适用：经营复盘、增长诊断、效率分析、绩效归因。

| 方法 | 回答的问题 | 核心数据需求 | 常见陷阱 |
|---|---|---|---|
| 指标体系 / 北极星拆解 | 目标由哪些可动因子构成 | 指标口径、分子分母定义、时间序列 | 口径未与业务方签字，结论被推翻 |
| SMART 目标法则 | 目标是否合理、可执行、可考核 | 目标五要素信息（具体/可衡量/可达成/相关/有时限） | 五要素齐全但目标间无优先级；可衡量指标与战略脱节 |
| 漏斗分析 | 转化瓶颈在哪一步 | 分环节埋点或流程数据 | 环节定义与真实业务路径不符 |
| 对比分析 | 好不好、差多少 | 参照系：环比/同比/预算/同行 | 没有参照系就说"高/低" |
| 归因分析（杜邦/结构拆解/贡献度） | 变化由谁贡献 | 各因子的分解数据 | 相关当因果；遗漏交互项 |
| ABC 分层 / 帕累托 | 资源该投向哪里 | 对象维度的价值分布 | 只看占比不看成本 |
| 健康度评分 | 现状处于什么水平 | 各维度基准值与权重（需业务确认） | 权重拍脑袋且无敏感性检查 |
| 留存/复购/ cohort | 用户质量趋势 | 分队列行为数据 | 队列窗口选择误导结论 |

## 三、通用方法（两式共用）

- **金字塔原理**：结论先行，每层 MECE；报告结构强制遵守。
- **STAR 访谈**：阶段 0-1 需求访谈用。
- **5Why 根因**：从现象逐层追问到可行动的根因；超过 3 层还是"人不行"则说明拆得不对。
- **外部基准扫描**：任何内部结论都要问"外部参照是什么"，参照系缺位时降级表述（"行业内常见区间为…，本项目数据为…，可比性有限"）。

## 四、选型决策话术（向用户确认框架时）

1. 这份报告的最终决策是"要不要做/选哪个方向"→ 偏咨询式；
2. 最终决策是"哪里出了问题/怎么改进"→ 偏经营式；
3. 两者都有 → 混合，明确哪些章节用哪套方法，避免框架混用导致逻辑断裂。
