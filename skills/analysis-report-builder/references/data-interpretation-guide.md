# 数据结果解读指南

> 用途：作为分析报告类 Agent Skill 的补充知识，与《分析模型与手段选型决策指南》配套——选型指南管"用什么分析"，本指南管"**分析出的结果怎么读、怎么下结论、怎么避免误读**"。
>
> 核心原则：**数据 + 标准 = 判断**。孤立的数据没有任何意义，任何解读都必须先建立参照系（基准），再描述事实，最后才允许给结论。

---

## 〇、解读总框架：四层递进

每一份数据结果的解读，都应沿四层递进，**层级越高越谨慎**：

| 层级 | 回答 | 示例 | 允许的证据强度 |
|---|---|---|---|
| L1 描述事实 | 数据是什么？ | "Q2 销售额 1.2 亿，环比 +8%" | 数据本身 |
| L2 对比定位 | 算高还是算低？ | "高于年度月均 15%，但低于大促目标 5%" | 数据 + 基准 |
| L3 解释原因 | 为什么是这样？ | "增长主要由 A 品类贡献（贡献度 62%）" | 数据 + 归因证据 |
| L4 给出启示 | 所以该怎么办？ | "建议保持 A 品类投入，排查 B 区域下滑" | L1~L3 全部扎实 |

**铁律**：
- 不允许跳级下结论——没有 L2 的基准对比，就没有资格说"表现好/差"；没有 L3 的归因证据，就没有资格说"因为……所以……"。
- 解读措辞必须与证据层级匹配：L1 用"数据显示"，L2 用"相较于……来看"，L3 用"可能与……有关/经拆解主要源于"，L4 用"建议/可考虑"。**"可能""主要源于""倾向于"等限定词不是示弱，是严谨。**

## 一、描述性结果的解读：先建参照系

### 1.1 解读前先问"和谁比"——基准选择

| 基准类型 | 回答的问题 | 适用 |
|---|---|---|
| 目标值/预算值 | 是否达成预期 | 考核、经营复盘 |
| 历史均值/中位数 | 是否偏离常态 | 日常监控 |
| 同比（上年同期） | 长期趋势，剔除季节性 | 有季节性的业务（电商、旅游） |
| 环比（上一周期） | 短期变化 | 高频运营监控 |
| 定基比 | 相对固定基期的累计变化 | 战略进展跟踪 |
| 行业金标准/竞品 | 相对竞争力 | 对外对标 |

**解读要点**：
- **季节性业务看同比，不看环比**——11 月 GMV 环比 10 月大涨是大促使然，不能解读为"经营改善"。
- **同比环比要联读**：同比增、环比降，可能是季节性回落而非恶化；两者同向才是强信号。
- **特定事件前后对比**（版本发布、活动、投放）是量化动作效果的首选，但要控制其他变量。

### 1.2 三类基本衡量

| 衡量什么 | 用什么 | 解读口径 |
|---|---|---|
| 整体大小 | 与均值/中位数/目标/行业标准比 | "处于历史高位/低位""达成率 x%" |
| 整体波动 | 变异系数、标准差跨期对比 | 先区分波动来源：周期性 / 内部因素 / 外部因素 / 数据传输问题 / 意外事件——前三类属正常波动，后两类先查数据质量 |
| 变化趋势 | 时间维度（同比/环比/定基/事件前后）+ 空间维度（产品/区域/用户分组） | 趋势要至少 3 个连续数据点同向才可称"趋势"，两点之间只是"变化" |

### 1.3 可比性原则（解读的前置检查）

下任何对比结论前，必须确认：**对比对象同类型、指标口径同质、时间窗口等长、样本结构一致**。拿淘宝 GMV 与 B 站 GMV 对比、拿含大促的月份与平常月份对比、拿口径调整前后的数据对比，都是无效解读。

## 二、统计结果的解读

### 2.1 假设检验三件套：p 值、效应量、置信区间

| 统计量 | 正确解读 | 常见误读 |
|---|---|---|
| **p 值** | 在零假设为真时，观察到当前或更极端结果的概率。p<0.05 只说明"差异不太像偶然" | ❌"p<0.05 说明效应很大/很重要"；❌"p>0.05 说明没有差异"（也可能是样本量不足） |
| **效应量**（Cohen's d、η²、R²、Cramer's V） | 差异/关联的**实际大小**。大样本下再小的差异也能 p<0.05 | ❌ 只报 p 不报效应量——"显著"≠"重要" |
| **置信区间** | 参数估计的不确定性范围，同时包含显著性（是否跨 0）与精度（宽窄）信息 | ❌"真实值有 95% 概率落在区间内"（频率学派下真实值是定值） |

**解读规则**：
1. **三件套必须一起报**：点估计 + 置信区间 + 效应量，p 值只是门槛不是结论。
2. p 值对样本量极度敏感——样本 10 万时 d=0.05 的微小差异也"显著"；解读时永远问一句："这个差异换算成业务量级有多大？"
3. **不显著 ≠ 没有效应**：置信区间很宽的不显著，含义是"证据不足"，不是"没有差异"。

### 2.2 相关系数

| r 值 | 解读 |
|---|---|
| ±0.8~1.0 | 强相关 |
| ±0.5~0.8 | 中等相关 |
| ±0.3~0.5 | 弱相关 |
| ±0~0.3 | 极弱/基本无线性相关 |

**解读规则**：
- 相关系数显著时，**只有四种可能**：X→Y、Y→X、第三变量同时驱动两者、纯属巧合。**相关本身不指明是哪一种**。
- r 衡量的是**线性**关系；r≈0 不代表"无关"，可能是非线性关系（看散点图！）。
- 异常值可以凭空制造或摧毁相关性——解读前先看散点图。
- 分组数据合并后相关方向可能反转（辛普森悖论，见第四节）。

### 2.3 回归结果

| 输出 | 解读 |
|---|---|
| 回归系数（连续变量） | 其他变量不变时，X 每增加 1 单位，Y 平均变化 β |
| 回归系数（虚拟变量） | 其他变量不变时，该组比参照组平均高/低 β |
| t 值 / p 值 | 该系数是否显著不为 0；不显著 = 没有足够证据说明该变量有独立贡献 |
| R² | 模型解释了 Y 变异的比例；**R² 高 ≠ 模型好**（可能过拟合、可能有遗漏变量） |
| 调整 R² | 惩罚变量个数后的拟合优度；**多元回归报告时以调整 R² 为准** |
| F 检验 | 所有自变量联合起来是否显著；F 不显著则整个方程意义存疑 |
| 残差诊断 | 残差应无模式、近似正态、方差齐；残差有趋势 = 模型漏掉了结构（非线性/遗漏变量） |

**解读规则**：
- 系数的"其他变量不变"前提决定了它是**条件关联**，不是因果效应——除非有随机实验或严谨的因果识别设计。
- **禁止外推**：回归关系只在观测数据范围内有效，超出范围预测是猜测。
- 报告时报告调整 R² 而非 R²；加入新变量后调整 R² 不升反降，说明新变量没有贡献。

### 2.4 模型评估指标（含机器学习）

**分类模型**——先问"业务上误报和漏报哪个代价大"：

| 指标 | 回答 | 适用倾向 |
|---|---|---|
| 准确率 Accuracy | 整体猜对的比例 | 类别均衡时参考；**不平衡数据下会严重失真**（99% 正常交易时全猜"正常"也有 99% 准确率） |
| 精确率 Precision | 预测为正的里面有多少是真的 | 误报代价高：垃圾邮件、推荐、风控放款 |
| 召回率 Recall | 真实的正例抓出了多少 | 漏报代价高：疾病筛查、欺诈检测 |
| F1 | 精确率与召回率的调和平均 | 需要两者兼顾、类别不平衡时优于准确率 |
| AUC-ROC | 模型区分正负例的整体能力 | 比较模型整体性能；0.5=瞎猜，>0.8 通常可用 |
| PR 曲线/AUPRC | 聚焦正例的精确-召回权衡 | **类别严重不平衡时优于 ROC** |

**回归模型**：
| 指标 | 解读要点 |
|---|---|
| MAE | 平均绝对误差，量纲与业务一致，最直观 |
| RMSE | 对大而少的严重错误更敏感；RMSE 明显大于 MAE = 存在少量巨大误差 |
| MAPE | 百分比误差，跨量纲可比；但真实值接近 0 时会爆炸，慎用 |
| R² | 解释变异比例；**测试集 R² 才有意义**，训练集 R² 高可能是过拟合 |

**解读规则**：
- **没有最好的指标，只有最匹配业务成本的指标**——先把误报/漏报成本排个序，再选主指标。
- 阈值可调：降阈值 → 召回升、精确降；解读分类结果时必须说明所用阈值。
- 多指标联读，任何单一指标都可能掩盖模型缺陷。

## 三、归因与异动结果的解读

1. **贡献度话术**："X 指标本期环比变动 n%。经拆解，A 因素贡献 m%，B 因素贡献 k%，二者合计解释了变动的 j%。"——各因素贡献度之和应能覆盖总变动，否则说明拆解维度不全，必须声明"其余 y% 来自未拆解因素"。
2. **乘积指标的双因素解读**：如"销售额 = 流量 × 转化率 × 客单价"，整体上升时若某因素下降，必须同时报告——"增长完全由流量拉动，转化率实际在恶化"，避免整体向好掩盖结构恶化。
3. **占比变化 ≠ 绝对值变化**：某渠道销售占比下降，可能是该渠道萎缩，也可能是其他渠道增长更快——占比解读必须搭配绝对值。
4. **先排除数据问题再解读业务**：异动解读的第一候选永远是"口径调整/埋点变更/数据延迟/统计周期变化"，确认数据无误后才进入业务归因。

## 四、解读常见陷阱（反模式清单）

| 陷阱 | 表现 | 对策 |
|---|---|---|
| **相关当因果** | 雪糕销量与溺水人数相关 → "禁售雪糕防溺水"（共同原因：天热） | 寻找混杂变量；因果结论需要实验或准实验设计 |
| **幸存者偏差** | 只看留存下来的样本："A 类用户贡献 70% 销售额 → 全部预算投 A 类"（忽略了已流失的 B 类潜力用户） | 追问"没出现在数据里的样本是谁" |
| **辛普森悖论** | 每个业务线男生通过率都高于女生，合并后男生反而更低 | 分组结论与合并结论冲突时，以分组为准并检查各组样本结构 |
| **样本谬误** | 样本量不足、首批活跃用户代表全体、混入脏数据 | 解读前先报样本量与选取方式；小样本结论加"初步迹象"限定 |
| **基数谬误** | " fraud 识别模型 99% 准确"但欺诈率仅 0.1%，报警的绝大多数是误报 | 概率解读必须结合先验基率 |
| **均值陷阱** | 平均收入被少数高收入者拉高 | 均值中位数一起报；分布偏态时以中位数为准 |
| **比率分母陷阱** | 小分母导致比率剧烈波动："转化率暴涨 300%"（从 1 单到 4 单） | 比率结论必须附绝对量 |
| **数据挖掘/p-hacking** | 同一批数据反复检验直到"发现"显著结果 | 多重比较需校正（Bonferroni 等）；事后发现的关系标注为"假设"而非"结论" |
| **控制变量缺失** | A/B 对比时两边营销方式都不同，结论无法归因 | 对比前确认"除被测因素外其他条件一致" |
| **个人经验代替标准** | "转化率 30% 太低了，应该能到 75%"（无行业依据） | 判断必须基于标准：历史基准、行业基准、目标基准，三者至少居一 |
| **过度外推** | 用回归线预测观测范围外的情形 | 明确标注有效区间 |
| **精确度幻觉** | "增长 8.3742%"（样本只有几十） | 有效数字与样本精度匹配；业务报告一般保留 1 位小数足够 |

## 五、结论话术模板（可直接嵌入 Skill）

**基准对比结论**：
> 「{指标}本期为 {值}，{环比/同比} {±n%}，{高于/低于/达成} {基准} {x%}，处于 {历史区间} 的{高位/中位/低位}。」

**异动归因结论**：
> 「{指标}本期{环比}变动 {n%}。经{拆解方法}下探，{因素A}变化 {N}，对整体变动贡献 {m%}，{是主要驱动/部分解释}；其余 {y%} 的变动来自{未覆盖因素}，建议进一步排查{方向}。」

**统计检验结论**：
> 「两组差异在统计上{显著/不显著}（p={值}），效应量 {d/η²}={值}，属于{小/中/大}效应；95% 置信区间为 {区间}。换算成业务量级：{业务含义}。」

**相关性结论**（防因果误读版）：
> 「{X} 与 {Y} 呈{强/中/弱}{正/负}相关（r={值}）。该关联{可能/不可能}由以下机制解释：{候选机制}；但当前数据{无法/可以}支持因果判断，{如需因果结论，建议 A/B 实验验证}。」

**模型效果结论**：
> 「模型在测试集上 {主指标}={值}（{业务基准对比}），其中误报率 {x}、漏报率 {y}；按当前业务成本结构，{可用/需调阈值至……/不可用}。」

**趋势判断结论**：
> 「{指标}连续 {n} 期{上升/下降}，且{同比/环比}同向，可判断为{趋势性变化/短期波动}；驱动因素主要为{……}，预计{谨慎外推 + 前提条件}。」

## 六、给 LLM/Skill 的执行建议

1. **解读前自检三问**（写入 skill 的解读前置步骤）：① 基准是什么？没有基准不下好坏判断。② 可比性成立吗？口径/周期/样本结构是否一致。③ 数据本身可信吗？先排除口径调整、埋点变更、数据延迟。
2. **分层输出**：强制按"L1 事实 → L2 对比 → L3 解释 → L4 启示"组织解读段落，每层标注证据来源；LLM 不得在没有 L3 证据时输出因果措辞（"导致""因为"），只允许"相关""伴随""可能源于"。
3. **限定词规则**：证据为相关性时用"相关/伴随"；有归因拆解时用"主要源于/贡献约"；有实验证据时才用"导致/提升"。
4. **数字规范**：百分比变化必须同时给出基期绝对值；比率指标必须给分母量级；所有结论性数字保留与样本精度匹配的有效位数。
5. **显著性转译**：凡涉及统计检验，必须把统计语言转译为业务语言——"显著（p<0.05）"之后必须跟一句"这意味着……（业务量级/业务含义）"。
6. **陷阱触发器**：当解读中出现"占比变化""合并分组对比""小样本比率""相关关系"等信号词时，自动检查第四节对应陷阱（占比≠绝对值、辛普森悖论、分母陷阱、因果误读）。
