2. **dashi-ppt-skill（chuspeeism）**：职场 PPT Skill。12 套主题/1020 版式/8576 控件/浏览器编辑控制台，Node.js，输出 HTML+PDF+PPTX。侧重"视觉主题丰富+生成后可编辑"。AnaPPTSkills 阶段6推荐配合此 skill。
3. **guizang-ppt-skill（op7418）**：单文件 HTML 横向翻页 PPT。两套视觉系统（电子杂志+瑞士国际主义），npx skills add 安装，输出单文件 HTML。侧重"强设计风格+叙事表达"。
